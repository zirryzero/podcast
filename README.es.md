# Podcast Channel - "Hello World pale blue dot" 🎙️

[English Version](README.md) | [Versión en Español](README.es.md)

Landing page responsiva y moderna para un podcast sobre desarrollo de software, cultura de programación e historia de la tecnología.

## 🌟 Características destacadas
- **HTML5 semántico y CSS3 moderno** con arquitectura de diseño limpia.
- **Reproductores de Spotify integrados**: Escucha episodios destacados directamente en el sitio.
- **Navegación responsiva**: Menú adaptativo móvil y disposición fluida de escritorio con Grid y Flexbox.
- **Tipografía e Iconografía**: Integración de Google Fonts (*IBM Plex Sans*, *IBM Plex Mono*) y Font Awesome.
- **Elementos interactivos**: Enlaces de ancla con scroll suave, botones de llamada a la acción y redes sociales.

## 🛠️ Tecnologías utilizadas
- **HTML5**
- **CSS3** (Flexbox, CSS Grid, Transiciones, Media Queries)
- **Font Awesome 4.7.0**
- **Google Fonts** (`IBM Plex Sans`, `IBM Plex Mono`)
- **Spotify Embeds**

## 🚀 Visualización local
1. Clona el repositorio:
   ```bash
   git clone https://github.com/zirryzero/podcast.git
   ```
2. Entra a la carpeta del proyecto:
   ```bash
   cd podcast
   ```
3. Abre `index.html` directamente en tu navegador o ejecuta un servidor estático:
   ```bash
   # Con Python
   python -m http.server 3000

   # O con Node.js
   npx serve .
   ```
4. Ingresa a `http://localhost:3000` en tu navegador.
