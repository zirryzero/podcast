# Podcast Channel - "Hello World pale blue dot" 🎙️

[Versión en Español](README.es.md) | [English Version](README.md)

Modern, responsive landing page for a podcast covering software development, programming culture, and technology history.

## 🌟 Highlights & Features
- **Semantic HTML5 & Modern CSS3** with clean layout architecture.
- **Embedded Spotify Podcast Players**: Listen to featured episodes directly from the page.
- **Responsive Navigation**: Adaptive mobile drawer navigation and fluid desktop grid layout.
- **Accessible Typography & Icons**: Integrated Google Fonts (*IBM Plex Sans*, *IBM Plex Mono*) and Font Awesome icons.
- **Interactive Elements**: Smooth scrolling anchors, CTA buttons, and interactive social links.

## 🛠️ Built With
- **HTML5**
- **CSS3** (Flexbox, CSS Grid, Transitions, Media Queries)
- **Font Awesome 4.7.0**
- **Google Fonts** (`IBM Plex Sans`, `IBM Plex Mono`)
- **Spotify Embeds**

## 🚀 Getting Started Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/zirryzero/podcast.git
   ```
2. Navigate into the directory:
   ```bash
   cd podcast
   ```
3. Open `index.html` directly in your browser or run a local static server:
   ```bash
   # Using Python
   python -m http.server 3000
   
   # Or using Node.js npx
   npx serve .
   ```
4. Visit `http://localhost:3000` in your web browser.
