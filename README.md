# Podcast Channel - "Hello World pale blue dot" 🎙️

Landing page responsiva para un podcast sobre desarrollo de software y tecnología.

## 🚀 Demostración
Puedes ver el sitio en vivo o abrir localmente `index.html`.

## 🛠️ Tecnologías utilizadas
- **HTML5** semántico
- **CSS3** (Flexbox, Grid, diseño responsive)
- **Font Awesome 4.7.0** (Iconografía)
- **Google Fonts** (IBM Plex Sans, IBM Plex Mono)

## 📂 Estructura del proyecto
```text
podcast/
├── font-awesome-4.7.0/   # Iconografía y hojas de estilo de Font Awesome
├── img/                  # Imágenes, logotipos e iconos del sitio
├── index.html            # Estructura principal de la landing page
├── styles.css            # Estilos personalizados y responsive design
├── .gitignore            # Archivos excluidos de control de versiones
└── README.md             # Documentación del proyecto
```

## 💻 Visualización local
1. Clona el repositorio:
   ```bash
   git clone https://github.com/zirryzero/podcast.git
   ```
2. Entra a la carpeta del proyecto:
   ```bash
   cd podcast
   ```
3. Abre [index.html](file:///c:/Users/harol/OneDrive/Documents/Code/podcast/index.html) en tu navegador preferido.
